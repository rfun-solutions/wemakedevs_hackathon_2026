# T7: Dash0 MCP + Agent0 runTask/waitForTask with a bearer token (2026-11-08)

- **Bearer auth works non-interactively.** `POST https://api.us-west-2.aws.dash0.com/mcp`, headers `Authorization: Bearer $DASH0_TOKEN`, `Accept: application/json, text/event-stream`. `initialize` returns protocol 2025-03-26, serverInfo Dash0 1.0.0 (JSON, ~0.26 s). No session id needed.
- `tools/list`: 31 tools incl. `runTask`, `waitForTask`, `promql`, `sql`, `getSpans`, `getLogRecords`, `getWebEvents`, `listWebsites`, `getServiceCatalog`, `getMetricQuery`, `listSlos`.
- **runTask args:** required `message` and `dataset` (use `"default"`); optional `threadIdOrUrl`, `timeoutSeconds` (default 25, max 45), `networkLevel`, `modelClass` (light|standard|advanced|premium), `reasoningEffort` (low..max). **waitForTask args:** required `threadIdOrUrl`, `dataset`; `timeoutSeconds` default 300, max 600. (The T7 plan used `task`; wrong name.)
- **Response is `text/event-stream`** (`event: message` + `data: {json-rpc}`), not plain JSON. Parse `data:` lines. Answer is in `result.content[0].text`, followed by an "Open conversation in Dash0" link containing `thread_id=<uuid>`.
- **Latency (3 runs, question "In one plain sentence ... is service kc-t2 healthy in the last hour?", default model class `advanced`, effort `high`):** runTask returned the final answer in 42.0 s, 36.3 s, 31.7 s (with `timeoutSeconds: 45`). In all runs the answer arrived inside runTask, so waitForTask was immediate (+0.4 s) and not needed. A further run (light/low attempt did not apply, same defaults) took 30.9 s. So 31-42 s, over the 20 s threshold for D3.
- **Answer quality:** correct and usable. "Yes/Mostly yes: kc-t2 (listed as kc-t2-api) healthy, no alerts, about 5 of 66-67 requests (~7-8%) failed, logs label them simulated." It resolved the service name itself. Wording differs per run.
- **Credits/usage:** the response carries no credit or token usage. Only a hint: "Agent0 ran on the `advanced` model class at `high` reasoning effort." Token auth means the thread is not attributed to a user and is not visible in the Dash0 UI ("With OAuth it is"). Credit balance not checked in the UI (no browser); check manually.
- **Usable in an app?** Technically yes (server-side, bearer, one POST). But 30-45 s and nondeterministic, so only as a cached/async result (compute in a background job, serve the stored sentence), never in a request path. Untested whether `modelClass: light` + `reasoningEffort: low` cuts latency; try that first if D3 is built.
